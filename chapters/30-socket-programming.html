PART 7 · NETWORKING AND SOCKETS

Chapter 30 — Socket Programming: হাতেকলমে

একটা ন্যূনতম TCP server, C-তে — প্রতিটা লাইন এতক্ষণের theory-র প্রমাণ।

// ন্যূনতম echo server — error handling ইচ্ছা করে বাদ
int server_fd = socket(AF_INET, SOCK_STREAM, 0);   // ১

struct sockaddr_in addr = {0};
addr.sin_family = AF_INET;
addr.sin_port   = htons(8080);
bind(server_fd, (struct sockaddr*)&addr, sizeof(addr)); // ২

listen(server_fd, 128);                            // ৩

while (1) {
    int client_fd = accept(server_fd, NULL, NULL); // ৪
    char buf[1024];
    int n = read(client_fd, buf, sizeof(buf));     // ৫
    write(client_fd, buf, n);                      // ৬
    close(client_fd);                              // ৭
}

লাইন ধরে ধরে — OS-এর চোখে কী ঘটলো:

  1. socket(): System call → kernel একটা socket object বানালো, fd দিলো। SOCK_STREAM মানে TCP।
  2. bind(): "Port 8080 আমার" — kernel-এর port table-এ দাবি নথিভুক্ত। অন্য কেউ আগেই নিলে এখানেই EADDRINUSE — তোমার চেনা সেই "port already in use"।
  3. listen(fd, 128): Socket টা listening mode-এ; 128 হলো accept queue-র backlog (Chapter 26!)। এই মুহূর্ত থেকে kernel নিজে নিজে handshake করে connection জমাতে থাকবে।
  4. accept(): Accept queue খালি থাকলে process এখানে block — Waiting state। Connection এলে জাগে, হাতে পায় নতুন fd।
  5. read(): Receive buffer-এ data না থাকলে block; থাকলে copy। (এই যে ৪ আর ৫-এ blocking — এটাই এই server-এর সীমা: এক সময়ে এক client। Chapter 28-29 এর সমাধান তো এখন জানোই।)
  6. write(): Send buffer-এ copy → kernel পাঠাবে।
  7. close(): fd ছাড়ো → kernel TCP-র বিদায়-নৃত্য (FIN/ACK) চালায়।
আসল শিক্ষা

মাত্র ৭টা system call-এ একটা network server — কারণ ভারী কাজের সবটাই kernel-এ: handshake, reliability, buffering, retransmission। Application-এর ভূমিকা আসলে orchestration — kernel-এর তৈরি জিনিসগুলো চাওয়া, আর bytes-এর অর্থ বোঝা (HTTP parse করা ইত্যাদি)। Express দিয়ে যে server লেখো, সেটা এই ৭ call-এর উপরে সাজানো অনেকগুলো সুবিধার স্তর মাত্র।

EXPERIMENT

কোনো C লাগবে না — দুই terminal-এ: nc -l 8080 (server) আর nc localhost 8080 (client), টাইপ করো — chat! তারপর তৃতীয় terminal-এ ss -t | grep 8080 (macOS: netstat -an | grep 8080) — নিজের বানানো connection-টার state দেখো। Linux-এ strace nc -l 8081 চালালে উপরের socket→bind→listen→accept ধারাটা লাইভ দেখবে।
