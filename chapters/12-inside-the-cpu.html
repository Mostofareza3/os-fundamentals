PART 4 · CPU

Chapter 12 — CPU-র ভিতরে

যেখানে আসল "কাজ" হয় — সেই যন্ত্রটার minimum viable mental model।

ভিতরের যন্ত্রপাতি

  • ALU (Arithmetic Logic Unit): যোগ-বিয়োগ-তুলনা-bitwise — actual হিসাবের জায়গা।
  • Control Unit: Instruction পড়ে ঠিক করে কোন যন্ত্রাংশ কী করবে — অর্কেস্ট্রার conductor।
  • Registers: CPU-র ভিতরের হাতেগোনা কয়েকটা ultra-fast storage slot। যেকোনো হিসাবের operand আগে register-এ আসে। এর মধ্যে দুটো special:
    • Program Counter (PC): পরের instruction-এর address। "Program চলছে" মানে এই register এগোচ্ছে।
    • Instruction Register: এই মুহূর্তে execute হওয়া instruction।
  • Cores: আধুনিক CPU আসলে এক chip-এ একাধিক স্বাধীন CPU — প্রতিটা core-এর নিজস্ব ALU, registers, L1/L2 cache। 8-core মানে সত্যিকারের ৮টা কাজ একসাথে।
  • Clock speed: প্রতি second-এ কত cycle (3GHz = ৩০০ কোটি)। প্রতি cycle-এ CPU-র যন্ত্রপাতি এক ধাপ এগোয়।

একটা instruction-এর জীবনচক্র

Fetch    → PC যেখানে দেখাচ্ছে, memory থেকে সেই instruction আনো
Decode   → instruction-টা কী বলছে বোঝো (add? load? jump?)
Execute  → ALU দিয়ে কাজটা করো
Memory   → দরকার হলে memory read/write করো
Writeback→ result register-এ লেখো
   ↺ PC বাড়াও (বা jump হলে নতুন address বসাও), আবার Fetch

তোমার পুরো career-এর সব code — React component থেকে SQL query — শেষ বিচারে এই লুপ: fetch, decode, execute, কোটি কোটি বার প্রতি second-এ। High-level ভাষা যত জাদুই দেখাক, নিচে নেমে সবকিছু এই সরল চক্রে দাঁড়ায়।

CONNECTION

Chapter 5-এর stack pointer, Chapter 4-এর entry point, সামনের Chapter 17-এর context switch — সবকিছু ঘোরে registers-এর চারপাশে। Process-এর "execution state" মানে মূলত: registers + PC + stack pointer-এর snapshot। এই বাক্যটা মনে রেখো, context switching-এ কাজে লাগবে।
