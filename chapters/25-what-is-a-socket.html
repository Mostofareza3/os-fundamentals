PART 7 · NETWORKING AND SOCKETS

Chapter 25 — Socket কী?

Network-কে OS যেভাবে file বানিয়ে দেয়।

Abstraction-টা

Network hardware-এর জগৎ raw packet-এর জগৎ। কিন্তু তুমি চাও "ওই server-এর সাথে একটা connection, যেখানে আমি bytes লিখবো আর পড়বো।" এই চাওয়াটার OS-দেওয়া রূপ হলো socket — network communication-এর একটা endpoint, kernel-এর তৈরি ও রক্ষণাবেক্ষণ করা একটা object।

সবচেয়ে সুন্দর অংশ: socket-ও পাও একটা file descriptor হিসেবে — file-এর মতোই (Chapter 21)! একই read()/write() চালে, একই fd table-এ বসে। Unix-এর সেই বিখ্যাত দর্শন — "everything is a file (descriptor)" — এখানে পুরো জৌলুসে।

ঠিকানা: IP + port

একটা TCP connection-কে uniquely চেনা যায় চারটা জিনিসে: (client IP, client port, server IP, server port)। IP machine চেনায়, port সেই machine-এর ভিতরে কোন application চেনায়। Server একটা well-known port-এ বসে থাকে (443, 5432...); client-এর port টা OS নিজেই একটা খালি নাম্বার থেকে দিয়ে দেয় (ephemeral port)। এই চার-টুপল আলাদা হলেই connection আলাদা — এজন্যই এক server port-এ হাজারো client একসাথে ঝুলতে পারে।

Client app                              Server app
   │ write("GET /")                          ↑ read() → "GET /"
   ↓                                         │
socket fd                               socket fd
   ↓                                         ↑
Client kernel (TCP/IP stack)            Server kernel (TCP/IP stack)
   ↓                                         ↑
   └───────── network (packets) ─────────────┘

দুই পাশের application শুধু নিজ নিজ socket দেখে; packet-এর ঝামেলা পুরোটা দুই kernel-এর।

Server side-এর জীবনচক্র

Server-এ socket-এর ব্যবহারটা একটু আলাদা ছন্দে চলে — নামগুলো চিনে রাখো, সামনে লাগবে:

  1. socket() — একটা socket বানাও
  2. bind() — "আমি port 8080-এর মালিক"
  3. listen() — "connection নিতে প্রস্তুত" (এটা listening socket)
  4. accept() — একেকটা আগত connection-এর জন্য নতুন একটা socket ফেরত দেয় — data আদান-প্রদান ওটাতেই

খেয়াল করো: listening socket আর connection socket আলাদা জিনিস। app.listen(8080) লেখার সময় Node ভিতরে ঠিক এই চারটা ধাপই চালায়।

CAN I EXPLAIN THIS?

  • Connection-এর চার-টুপল কী, আর এক port-এ বহু client কীভাবে?
  • Listening socket আর accepted socket-এর পার্থক্য?
