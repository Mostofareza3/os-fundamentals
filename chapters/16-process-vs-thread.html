PART 5 · PROCESS MANAGEMENT

Chapter 16 — Process vs Thread

Concurrency-র সব আলোচনার ভিত্তি — এই ছবিটা মাথায় গাঁথা চাই।

Thread কী

এতক্ষণ বলেছি "process চলে"। আরও সঠিকভাবে: process-এর ভিতরের thread চলে। Thread হলো execution-এর একক — একটা নিজস্ব instruction stream, নিজস্ব stack, নিজস্ব register state, আর নিজস্ব thread-local storage (TLS — errno এখানেই থাকে, এজন্যই এক thread-এর error অন্যের কাছে যায় না)। প্রতিটা process অন্তত একটা thread নিয়ে জন্মায় (main thread), চাইলে আরও বানাতে পারে।

মূল কথা: process হলো resource-এর container, thread হলো execution-এর unit। Address space, heap, open files — এগুলো process-এর সম্পত্তি; process-এর সব thread এগুলো share করে।

Process (একটা address space)
├── Thread 1   ├── Thread 2   ├── Thread 3
│   নিজস্ব:      │   নিজস্ব:      │   নিজস্ব:
│   • Stack     │   • Stack     │   • Stack
│   • Registers │   • Registers │   • Registers
│   • PC        │   • PC        │   • PC
│
└── সবাই মিলে shared:
    • Code (text)  • Heap  • Global data  • Open files/sockets

যার যার execution state আলাদা, সবার data জগৎ এক।

Share করা: আশীর্বাদ ও অভিশাপ

দুই processএক process-এর দুই thread
Memoryসম্পূর্ণ আলাদা (isolation)Heap/global shared
Communicationকষ্টের — pipe, socket, shared memory setup লাগে, প্রায়ই kernel-এর মধ্য দিয়েসহজ — একই variable-এ লেখো, অন্যজন দেখে
একজনের crashঅন্যজন বাঁচেপুরো process মরে — সবাই একসাথে ডোবে
তৈরির খরচবেশি (নতুন address space, page table) — CoW-এর পরেও thread-এর তুলনায় বেশিকম (শুধু stack + thread state)
Bug-এর ধরনInterface-এ ভুলRace condition, data corruption (Chapter 18)
COMMON MISCONCEPTION

"Thread is a lightweight process" — অসম্পূর্ণ, আর আসল point-টা miss করে। হালকা তো বটেই, কিন্তু defining পার্থক্য ওজনে না — address space-এ: process-রা আলাদা জগতে থাকে, thread-রা এক জগৎ share করে। এই sharing-ই thread-এর সব শক্তি আর সব বিপদের উৎস।

তোমার দুনিয়ায়

Node.js-এর model: এক process, তোমার JS চলে এক main thread-এ, কিন্তু ভিতরে libuv-এর একটা thread pool কিছু কাজ (file I/O, crypto, DNS) চালায়, আর V8-এর GC-ও আলাদা thread ব্যবহার করে। worker_threads খুললে সত্যিকারের আলাদা JS thread পাও। আর PM2 cluster mode? সেটা thread না — আলাদা process, এজন্যই ওদের মধ্যে memory share হয় না।
