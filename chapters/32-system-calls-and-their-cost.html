PART 8 · USER SPACE AND KERNEL SPACE

Chapter 32 — System Call আর তার দাম

Boundary পার হওয়ার হিসাব-নিকাশ — এবং সেটা ঘিরে গড়ে ওঠা engineering।

দামটা আসে কোথা থেকে

একটা syscall মানে সাধারণ function call না — মানে: mode switch (CPU state বদল), kernel-এ ঢুকে register বাঁচানো, syscall dispatch, argument validation, কাজ, তারপর পুরোটা উল্টো করে ফেরা। তার উপর আছে পরোক্ষ খরচ — kernel-এর code/data cache-এ ঢোকায় তোমার code-এর cache-এর কিছুটা দখল হয়ে যায় (Chapter 17-এর সেই cache দূষণের ছোট ভাই)।

কিন্তু ভারসাম্যটাও বলি: একটা syscall-এর নিজস্ব overhead nanoseconds-এর জগতে — আর তার ভিতরের কাজটা (disk read!) হতে পারে milliseconds-এর জগতে। অর্থাৎ overhead টা matter করে তখনই, যখন syscall গুলো ছোট এবং অনেক।

COMMON MISCONCEPTION

"System calls are slow — যত পারো এড়াও।" ভুল frame। সঠিক frame: syscall-এর একটা fixed per-call overhead আছে। ১টা syscall-এ 4MB পড়া = overhead তুচ্ছ। ১০ লাখ syscall-এ ৪ byte করে পড়া = overhead-ই মূল খরচ। শত্রু syscall না — শত্রু ছোট কাজে ঘনঘন boundary পারাপার।

এই হিসাব থেকে জন্ম নেওয়া কৌশলগুলো

  • Batching/buffering: ছোট ছোট write জমিয়ে এক syscall-এ পাঠানো। তোমার console.log-এর পিছনে stdout buffering, HTTP client-এর request pipelining — সব এই এক idea।
  • বড় buffer-এ পড়া: 64KB চেয়ে এক read, 1KB-র ৬৪ read না।
  • epoll-ই একটা জবাব: হাজার fd-র খোঁজ এক epoll_wait-এ (Chapter 29)।
  • io_uring — চূড়ান্ত রূপ: App আর kernel-এর মাঝে shared memory-র দুই ring (submission + completion)। App ring-এ request লিখে রাখে, kernel পড়ে কাজ করে result ring-এ রাখে — অনেক operation, প্রায় শূন্য boundary-পারাপার। পুরো design-টাই "syscall overhead"-এর বিরুদ্ধে যুদ্ধ।
  • vDSO (মজার fact): কিছু নিরীহ syscall (যেমন সময় জানা — gettimeofday) এত ঘনঘন ডাকা হয় যে kernel সেগুলোর জবাব user space-এই map করে দেয় — boundary পারই হতে হয় না।
EXPERIMENT (Linux)

দুটো তুলনা করো:
strace -c dd if=/dev/zero of=/dev/null bs=1 count=100000 (১ byte করে!)
strace -c dd if=/dev/zero of=/dev/null bs=100000 count=1 (এক চালানে)
-c flag syscall-এর গণনা আর সময়ের summary দেখায় — একই কাজ, syscall সংখ্যায় লক্ষগুণ পার্থক্য, সময়েও চোখে পড়ার মতো। এটাই এই chapter-এর পুরো থিসিস এক পরীক্ষায়।
