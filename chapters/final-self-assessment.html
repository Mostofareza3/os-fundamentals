Big picture আর process

  1. OS-এর kernel লাগে কেন — kernel-বিহীন জগতে কী কী ভাঙতো? (Ch 1)
  2. Program থেকে process হওয়ার মুহূর্তে ঠিক কী কী তৈরি হয়? (Ch 3-4)
  3. একই executable-এর দুই process আলাদা জগতে থাকে — কোন mechanism-এ? (Ch 3, 9)
  4. Stack কেন লাগে — function call-এর কোন সমস্যাটা সে solve করে? (Ch 5)
  5. Heap কেন লাগে — stack-এ সব রাখলে কী আটকাতো? (Ch 6)
  6. Scope আর lifetime-এর পার্থক্য, একটা bug-এর উদাহরণসহ। (Ch 6)
  7. fork() একবার ডাকলে দুইবার return — ব্যাপারটা কী? (Ch 15)
  8. Ready, Running, Waiting — কোন process কোন state-এ CPU চায়/চায় না? (Ch 15)

Memory

  1. প্রতিটা process-কে নিজস্ব virtual address space দেওয়ার তিনটা কারণ। (Ch 9)
  2. Page আর page table কী, কে ব্যবহার করে? (Ch 9)
  3. TLB না থাকলে প্রতিটা memory access-এ কী বাড়তি খরচ হতো? (Ch 9)
  4. Page fault সবসময় error না — একটা "ভালো" page fault-এর উদাহরণ। (Ch 9-10)
  5. Copy-on-write কীভাবে fork-কে সস্তা করে? (Ch 9)
  6. Minor vs major page fault — কোনটা কেন ভয়ংকর? (Ch 10)
  7. Swap আর virtual memory এক জিনিস না কেন? (Ch 9)
  8. DMA ছাড়া বড় I/O-তে CPU-র কী দশা হতো? (Ch 11)

CPU

  1. Program counter কী, jump/branch-এর সাথে সম্পর্ক কী? (Ch 12)
  2. CPU cache কেন লাগে — কোন gap-টা সে ভরাট করে? (Ch 13)
  3. Temporal আর spatial locality — নিজের code থেকে একটা করে উদাহরণ। (Ch 13)
  4. Array বনাম linked list — Big-O সমান হলেও বাস্তবে কে, কেন জেতে? (Ch 13)
  5. Pipelining কী বাড়ায় — latency না throughput? কেন? (Ch 14)
  6. Branch prediction ভুল হলে কী দাম দিতে হয়? (Ch 14)

Concurrency

  1. Process vs thread — "container vs execution unit" ব্যাখ্যা করো। (Ch 16)
  2. Thread-এর কোনটা নিজস্ব, কোনটা shared — এবং প্রতিটার কারণ। (Ch 16)
  3. Context switch-এ কী save/restore হয়, আর লুকানো খরচটা কোথায়? (Ch 17)
  4. counter++ কীভাবে race condition বানায় — instruction level-এ। (Ch 18)
  5. Mutex আর semaphore-এর পার্থক্য, একটা করে use case। (Ch 18)
  6. Shared state ছাড়া কি race condition সম্ভব? যুক্তি দাও। (Ch 18)
  7. CPU-bound-এ thread/process আর I/O-bound-এ event loop — কেন এই ভাগ? (Ch 19)

Storage আর file I/O

  1. File I/O-তে kernel জড়িত থাকতেই হয় কেন? (Ch 21, 31)
  2. File descriptor কী, কার table-এ থাকে? (Ch 21)
  3. write() return করা সত্ত্বেও data হারাতে পারে — পুরো ঘটনাটা। (Ch 21, 23)
  4. OS file data cache করে কেন, আর সেই cache ছাড়ে কখন? (Ch 23)
  5. inode-এ file-এর নাম থাকে না — তাহলে নাম থাকে কোথায়? (Ch 22)
  6. একই file দ্বিতীয়বার পড়া দ্রুত কেন — benchmark-এ এর তাৎপর্য কী? (Ch 23)

Network

  1. Socket কী, আর file descriptor হওয়াটা কেন সুবিধাজনক? (Ch 25)
  2. TCP "connection" জিনিসটা physically কোথায় থাকে? (Ch 26)
  3. SYN queue আর accept queue — কে ভরলে কী উপসর্গ? (Ch 26)
  4. Data আসার পর ঘুমন্ত server process জাগে কীভাবে — interrupt থেকে epoll পর্যন্ত। (Ch 27, 29)
  5. Thread-per-connection কোথায় ভাঙে, আর epoll ঠিক কী বদলে দেয়? (Ch 28-29)
  6. Event loop-এ ভারী sync কাজ চালালে kernel level-এ কী ঘটে? (Ch 29)

Boundary, virtualization আর সংযোগ

  1. Process সরাসরি hardware ছুঁতে পারে না — enforcement-টা কে করে, কীভাবে? (Ch 31)

  3. Container VM না কেন — namespace আর cgroup দিয়ে ব্যাখ্যা করো। (Ch 35-36)
