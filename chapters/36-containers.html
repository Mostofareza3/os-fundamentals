PART 10 · VIRTUALIZATION AND CONTAINERS

Chapter 36 — Containers

Docker-এর ভিতরের সত্য: নতুন কোনো জাদু না — এই বইয়ের চেনা জিনিসের চতুর সাজানো।

মূল সত্যটা আগে

Container কোনো VM না। Container হলো সাধারণ process — শুধু kernel তাকে সীমিত আর বিভ্রান্ত করে রাখে। কোনো guest OS নেই, নকল hardware নেই, আলাদা kernel নেই — host-এর kernel-ই সবার। docker run node মানে host-এ একটা node process-ই চলছে; host থেকে ps দিলে দেখাও যায় তাকে।

তাহলে "আলাদা machine" feeling-টা আসে কোথা থেকে? Linux kernel-এর দুটো feature থেকে:

  • Namespaces — "কী দেখতে পাবে": Process-এর বিভিন্ন দৃষ্টিশক্তির আলাদা আলাদা নকল সংস্করণ। PID namespace — container নিজেকে PID 1 দেখে, বাইরের কাউকে দেখে না; mount namespace — নিজের আলাদা filesystem গাছ (image-এর সেই ubuntu/alpine ফাইলগুলো — ব্যস, ফাইলই, kernel না!); network namespace — নিজস্ব IP, নিজস্ব port জগৎ। চেনা লাগছে? Virtual memory যা address-এর জন্য, namespace তা-ই বাকি সবকিছুর জন্য — প্রত্যেকে ভাবে জগৎটা তার একার।
  • cgroups — "কতটুকু পাবে": Process-দলের resource-এর রেশন কার্ড — এই দলের memory সর্বোচ্চ 512MB, CPU-র 50%, এতটুকু disk I/O। Docker-এর --memory/--cpus flag মানে স্রেফ cgroup-এর ঘর পূরণ। রেশন পার হলে? Memory-র বেলায় দলের কেউ খুন হয় — সেই কুখ্যাত OOM kill, তোমার Kubernetes pod-এর "OOMKilled"-এর জন্মস্থান।
VM:                              Container:
┌─App─┐ ┌─App─┐                  ┌─App─┐ ┌─App─┐   ← স্রেফ process,
│Guest│ │Guest│                  │ ns+ │ │ ns+ │      namespace-এ মোড়া
│ OS  │ │ OS  │ ← ২টা kernel!    │cgrp │ │cgrp │
├─────┴─┴─────┤                  ├─────┴─┴─────┤
│ Hypervisor  │                  │ এক Host Kernel│
│  Hardware   │                  │  Hardware    │
└─────────────┘                  └──────────────┘

এখন trade-off-টা নিজেই বলে দিতে পারবে: container start হয় process start-এর গতিতে (কোনো OS boot নেই), memory খায় process-এর মতো — কিন্তু সবাই এক kernel share করে, তাই isolation VM-এর মতো শক্ত না (kernel-এর ছিদ্র মানে সবার ছিদ্র), আর Linux container-এর Linux kernel-ই লাগে — এজন্যই তোমার Mac-এ Docker Desktop গোপনে একটা Linux VM চালিয়ে তার ভিতরে container চালায়। দুই chapter মিলে গেল।

EXPERIMENT (Docker থাকলে)

Container-এর ভিতরে: docker run --rm -it alpine ps aux — গোটা "machine"-এ হাতে গোনা process, node/shell-টার PID 1! তারপর host-এ (Linux host হলে) ps aux | grep <সেই command> — একই process, বাইরে থেকে সাধারণ PID-তে। এক process, দুই দৃষ্টিকোণ — এটাই namespace।
