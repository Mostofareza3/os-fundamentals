PART 6 · STORAGE

Chapter 22 — File Systems

Disk তো শুধু নাম্বার-দেওয়া block-এর সমুদ্র — "file" জিনিসটা বানায় কে?

Problem আর idea

Storage device-এর ভাষা: "block #48211 পড়ো/লেখো।" আমাদের ভাষা: "/home/reza/notes.md খোলো।" মাঝের অনুবাদক-টাই file system — disk-এর block গুলোর উপর সে বানায় নাম, hierarchy, permission, size — পুরো একটা সাজানো জগৎ।

Core building blocks (ext4-এর ছবিতে)

  • File = data blocks + metadata। Metadata থাকে inode-এ: size, owner, permission, timestamps, আর সবচেয়ে জরুরি — data কোন কোন block-এ আছে তার map। মজার fact: inode-এ file-এর নাম নেই।
  • Directory আসলে একটা বিশেষ file — যার content হলো একটা তালিকা: নাম → inode number। "File-এর নাম" আসলে directory-র সম্পত্তি। এজন্যই hard link সম্ভব — দুই নাম, এক inode।
  • Path resolution: /home/reza/notes.md খুলতে kernel হাঁটে: root-এর inode → তার entry-তে "home" → সেই inode → entry "reza" → inode → entry "notes.md" → অবশেষে file-এর inode। প্রতিটা ধাপে permission check।
  • Allocation: নতুন data-র জন্য কোন free block দেবে সেটা filesystem-এর কৌশল — ভালো filesystem চেষ্টা করে এক file-এর block গুলো কাছাকাছি রাখতে (sequential read-এর সুবিধা, Chapter 20)।
directory entry          inode #5021              disk blocks
"notes.md" → 5021   →   size: 8KB           →    [block 300][block 301]
                        (ext4 আসলে block-এর তালিকা না রেখে
                         extent রাখে — "block 300 থেকে ২টা")
                        owner: reza
                        perms: rw-r--r--
                        blocks: 300, 301

ext4 আধুনিক Linux-এর default — এতে আছে journaling: metadata বদলানোর আগে একটা log-এ intention লিখে রাখা, যাতে crash-এর পরে filesystem অসঙ্গত (corrupt) না থাকে। আর FAT? সেই সাদাসিধে পুরনো filesystem — permission নেই, journaling নেই — আজও pendrive/SD card-এ বেঁচে আছে কারণ সবাই এটা পড়তে পারে।

শেষ টুকরো — VFS (Virtual File System): kernel-এর ভিতরের সেই abstraction layer যার কারণে ext4, FAT, নেটওয়ার্ক filesystem — সবাইকে application একই open/read/write দিয়ে দেখে। Abstraction on abstraction — OS design-এর প্রিয় খেলা।

EXPERIMENT

ls -li চালাও — প্রথম column-টাই inode number। তারপর stat <filename> — এক file-এর পুরো inode-এর গল্প: size, blocks, links, timestamps। df -T . দিয়ে দেখো তোমার filesystem-টা আসলে কী (Linux-এ ext4, macOS-এ apfs)।
