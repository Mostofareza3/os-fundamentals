এই বই কার জন্য

ধরে নিচ্ছি তুমি একজন working software engineer — JavaScript/TypeScript বা যেকোনো high-level language-এ comfortable, Linux basics জানো, কিন্তু OS internals নিয়ে structured knowledge নেই। Process, thread, virtual memory, socket — term গুলো শুনেছ, কিন্তু এদের relationship মাথায় একটা coherent ছবি হয়ে দাঁড়ায়নি।

এই বই academic OS course না। Scheduling algorithm-এর exam question বা deadlock-এর mathematical proof এখানে পাবে না। পাবে একটা জিনিস — তোমার application-এর নিচে OS আসলে কী করছে, এবং সেটা তোমার code-এর performance আর behavior-এ কীভাবে impact ফেলে।

এই বইয়ের BACKBONE — একটাই গল্প
তুমি program লিখলে
  ↓ compiler executable বানালো
  ↓ OS executable load করলো → process তৈরি হলো
  ↓ process-এর নিজস্ব virtual address space তৈরি হলো
  ↓ CPU instruction execute করলো, cache/RAM access হলো
  ↓ দরকার পড়লে system call হলো → kernel কাজ করলো
  ↓ disk / network / device access হলো
  ↓ process আবার user space-এ ফিরে এলো

কীভাবে পড়বে

  • Sequence maintain করো। Chapter গুলো একটার উপর আরেকটা build করে। Virtual memory না বুঝে page cache বুঝবে না।

  • "Can I explain this?" গুলো skip কোরো না। নিজের ভাষায় explain করতে না পারলে বোঝা হয়নি — শুধু term চেনা হয়েছে।
